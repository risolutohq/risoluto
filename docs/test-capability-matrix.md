# Risoluto v1 Test Capability Matrix

This matrix is the migration ledger for replacing copied/stale tests with v1 behavior-first public-interface coverage.

Status meanings:

- `legacy_temp`: current tests are temporarily retained as safety coverage, but they are not the desired final shape.
- `replacement_planned`: behavior/public-interface replacement coverage is planned but not yet written.
- `replacement_in_progress`: replacement test exists or is being made green.
- `replaced`: replacement behavior coverage passes. Old stale assertions for this area may be deleted; retained lower-level/provider tests are no longer classified as stale legacy coverage when this matrix documents their valid behavior.
- `deleted_after_replacement`: old tests were removed after replacement coverage passed.
- `blocked`: blocked with concrete evidence and next action.
